# 실비소진 관리용 집계

실제 보험금 지급 여부·약관의 보장 한도를 판정하는 기능이 아니라 스케줄 기반 병원 관리용 수치다. 예약도 포함하며 회차 텍스트를 수동 수정해도 집계는 바뀌지 않는다.

- 집계 시작: **2026-07-01 포함**. 이전 기록은 표시하되 소진 횟수를 늘리지 않는다.
- 환자 식별: 챠트번호와 이름 모두 일치해야 한다.
- 도수치료: 매년 1월 1일 초기화. 충격파와 별도로 집계한다.
- 충격파: 집계 시작일 이후 첫 집계 대상 충격파 날짜를 기준으로 매년 같은 날짜에 초기화한다. 윤년 2월 29일은 평년에 2월 말일로 처리한다.
- `(본인)` 처방, 취소 예약, 병합된 자식 셀은 횟수를 늘리지 않는다. 본인 처방에는 이전까지의 누적을 표시한다.
- 신장분사는 횟수를 늘리지 않는다. 정수 표기(1, 2)는 도수치료, 소수 표기(2.5, 3.0)는 충격파의 해당 시점 횟수·갱신일을 표시한다. 구분 불가능한 처방은 추측하지 않는다.
- 내역창의 `갱신 일자`는 각 행의 다음 초기화 날짜다. 집계 시작 전 충격파는 갱신일이 없다.
- 동일 날짜의 스케줄은 행·열 순서로 집계한다. 스케줄 연동 로그와 예약을 중복 집계하지 않으며, 동일 환자·날짜·치료·처방의 독립 로그와 스케줄이 겹치면 스케줄을 우선한다.
- 회차 경고는 이 집계의 충격파 7회 이상, 도수치료 16회 이상을 사용한다. 주당 2일·7일 간격 경고는 기존 예약 날짜 기준을 유지한다.
- 원격 기록은 페이지 제한 없이 조회하고 화면의 최신 변경을 덮어 적용한다. 조회 실패는 0회로 대체하지 않으며 예약 확인 시 조회 실패하면 저장을 취소하고 재시도를 안내한다.
- 월 화면 환자 기록을 백그라운드에서 동시 2명씩 미리 조회한다. 메모리 캐시를 최대 60초간 재사용한다. 최초 조회가 끝나기 전에는 조회 중으로 표시될 수 있다. 저장 직전 경고는 캐시가 아닌 최신 조회 결과를 사용한다.

이 기능은 계산 결과를 DB 컬럼으로 저장하거나 기존 내역을 초기화·삭제하지 않는다. 과거 내역과 처방을 수정하면 계산 결과가 다시 산출된다.
